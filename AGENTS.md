# Project Rules

## Git commits

- NEVER add AI attribution to commits: no "Generated with ..." lines,
  no "Co-Authored-By" trailers for Devin or any bot/agent, no mention
  of AI tools in commit messages. Commit as the repo owner only.

## Git identity

- NEVER invent or alter git author/committer name or email. Always use
  the identity already configured in the repository. If none is
  configured, ask the user — never fabricate one.
